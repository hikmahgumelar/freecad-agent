# Real Use Case — ESP32 Antenna Enclosure

This branch captures the first realistic FreeCAD-Agent enclosure use case: a compact ESP32 enclosure with an external SMA antenna and a front USB-C opening.

Reference requirements:
- Two-piece enclosure: body + top cover.
- External antenna exits through a dedicated antenna opening/connector region.
- USB-C front opening remains accessible.
- Internal antenna/RF cable routing and clearance must be respected.
- Geometry must be generated as real FreeCAD geometry, then inspected before STL/final printing.

Reference visuals supplied by the user are kept as design references in this branch. The supplied collage shows exterior, side, front, interior and exploded views.
